# Custodia del evaluador

No almacenar aquí el oráculo real si el ejecutor tendrá acceso al repositorio.

El evaluador debe custodiar fuera del paquete del ejecutor:

- oráculo;
- criterios detallados de desviación;
- payload de corrección;
- hash del paquete reservado;
- firmas de congelamiento y cierre.

La mera separación por directorios en un repositorio accesible no constituye aislamiento. Este directorio solo documenta el procedimiento.
