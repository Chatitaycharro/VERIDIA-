# Veridia

No es un prompt. Es una costumbre.

Sitio estático: una página con un botón que copia el texto de Veridia al
portapapeles, para empezar con él una conversación con una IA.

Archivos:

- `index.html`: la página.
- `veridia.txt`: el texto de Veridia.
- `manual.md`: manual breve.
- `LICENSE`: licencia MIT.
